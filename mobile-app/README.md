# mobile-app

Expo app with Expo Router.

## Stack

- **Routing:** Expo Router (file-based)
- **Styles:** React Native `StyleSheet` for now. Consider NativeWind or another style lib for the final project.
- **State management:** None
- **Authentication:** None
- **EAS:** Not set up (no EAS Build/Submit configured)

## Run

```bash
npm install
npm start
```

Then use the dev tools to run on iOS, Android, or web.

# DATA 5570 | Building Software With Artificial Intelligence | Course Project Repository
This repository contains coursework and project code for DATA 5570, a course focused on building real software applications with AI assistance. The repo holds both a Django backend and a React Native mobile app, developed incrementally throughout the semester.
What's in this repo (and why you might care)

Django backend (myproject/, data5570_mycode/): A Python-based web backend serving as the API layer for the mobile app. Built with Django and structured for iterative development alongside course assignments.
React Native mobile app (mobile-app/): A cross-platform mobile frontend built with Expo and TypeScript, with Redux recently added for state management.
Course exercises & scratch code (hello.py, data5570_mycode/): Smaller scripts and experiments from early in the course — useful for seeing how the project evolved from simple beginnings.

If you're interested in:

How a full-stack mobile + backend app gets built from scratch in an academic setting,
How AI tooling is used throughout the software development lifecycle, or
A real example of Django + React Native/Expo working together,

then this repo is worth a look. If you're looking for a finished, polished product, keep in mind this is an active course project and is a work in progress.
High-level structure

myproject/ – Django project root and configuration
data5570_mycode/ – Course-specific Django app code
mobile-app/ – Expo/React Native frontend with TypeScript and Redux
